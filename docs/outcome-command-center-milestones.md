# 回復期病棟アウトカム司令塔 開発マイルストーン

## プロダクトゴール

患者ごとのFIM、AIリハビリ計画、退院課題、多職種の対応状況を一か所に集約し、対応の遅れや入力漏れを早期に発見する。担当者と期限を明確にして課題を解決し、在宅復帰率、FIM改善、回復期リハビリテーション病棟実績指数の向上につなげる。

公開実績は比較用の基準値として扱い、院内実測値、サンプル、AI推定値と明確に区別する。AIは意思決定や計画確定を行わず、医師・療法士・多職種の確認を支援する。

## M3 AI多職種カンファレンス

状態：開発中（第1スプリント完了）

第1スプリント実装済み：患者ごとのFIM推移、退院支援課題、リハビリAI計画、リハビリボイスを統合し、変化、阻害要因、未確認事項、今回決める事項を参照元付きで自動作成する。参加者、議事記録、決定事項を保存し、担当・期限付きアクションを司令塔へ連携する。

目的：カンファレンス前の情報収集を自動化し、会議を意思決定の時間に変える。

開発内容：

- PT、OT、ST、看護、医師、栄養、MSW記録の統合
- 前回カンファレンスからの変化要約
- 達成目標、未達目標、阻害要因の抽出
- 職種間の所見矛盾と未確認事項の表示
- 今回決めるべき事項の提案
- 決定事項から担当者・期限付きアクションを作成
- カンファレンス記録と参加者の保存
- AI根拠リンクと人による修正履歴

完了基準：カンファレンス資料が5分以内に生成され、全提案に参照元が表示されること。

- 在宅復帰の阻害要因ランキング
- 「次に確認すべきデータ」と「実行可能な対応」の提示
- 予測根拠、信頼度、対象外条件の表示
- AI予測と実際の結果の継続比較

安全条件：診断、退院先、治療内容をAIだけで決定しない。低信頼度の推定は表示せず、要確認として扱う。

完了基準：予測精度だけでなく、警告後の対応実施率、期限超過減少、偽警告率を評価できること。

## M7 西大和モデル実証導入

目的：実際の病棟で効果と安全性を証明する。

実証手順：

1. 現行業務とデータ項目のヒアリング
2. 2週間の現状時間測定
3. 匿名またはテストデータによる安全確認
4. 1病棟・限定患者で4週間試行
5. カンファレンスと退院支援機能を追加して8週間試行
6. 効果、安全性、操作負荷を評価
7. 病院承認後に対象病棟を拡大

導入判定指標：

- 記録・資料作成時間
- FIM入力漏れ
- 計画期限超過
- 退院課題の担当者未設定
- 期限超過アクション
- ユーザー継続利用率
- AI提案の修正率
- 重大な誤提案と患者取り違え件数

完了基準：重大事故0件、利用者合意、主要業務時間30%以上削減を満たし、本導入判断ができること。
